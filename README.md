# 내신 영단어 암기

고등 하위권 내신 영단어 암기 사이트입니다.

- **학생 화면**: https://cattailiscute.github.io/vocab-master_2026_10/
- **선생님 화면**: 위 주소 뒤에 `teacher.html`

## 구조

| 부분 | 위치 | 역할 |
|---|---|---|
| 화면 | GitHub Pages (이 저장소) | 학생·선생님이 여는 링크. 항상 켜져 있음 |
| 데이터 | 선생님의 **구글 시트** | 단어·학생·설정 입력, 시험 기록 저장 |
| 서버 | 구글 시트에 붙은 **Apps Script** (`apps-script/Code.gs`) | 채점, 진도 잠금, 시험지 생성, 예약 저장 |
| 시험지 보관 | 선생님의 **구글 드라이브** › `단어 시험지 (자동 저장)` 폴더 | 예약 시간마다 PDF 자동 저장 |

Mac을 꺼 두어도 학생 접속과 예약 저장 모두 작동합니다.

## 설치 (처음 한 번, 약 10분)

### 1. 구글 시트 + 서버 만들기
1. https://sheets.new 에서 새 구글 시트를 만들고 이름을 정합니다 (예: `영단어 암기 데이터`).
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 편집기에 있던 코드를 모두 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 **통째로 붙여넣고** 저장(💾)합니다.
4. 위쪽 함수 선택 칸에서 **`setup`** 을 고르고 **▶ 실행**을 누릅니다.
   - "승인 필요" → 본인 계정 선택 → "Google에서 확인하지 않은 앱" 화면에서 **고급 → (안전하지 않음)으로 이동 → 허용**을 누릅니다. 본인이 만든 스크립트라서 나오는 정상적인 안내입니다.
   - 실행이 끝나면 시트에 `단어 / 학생 / 설정 / 시험기록 / 진도 / 오답 / 예약` 탭이 생깁니다. 예시 단어 10개와 테스트 학생(1반 · 테스트 · 1234)도 함께 들어갑니다.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱**을 선택합니다.
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고, 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.

### 2. 사이트에 서버 주소 넣기
이 저장소의 `config.js`를 열고(GitHub 웹에서 연필 ✏️ 아이콘) 따옴표 안을 복사한 URL로 바꾼 뒤 **Commit changes**를 누릅니다.

```js
window.API_URL = 'https://script.google.com/macros/s/AKfy…/exec';
```

### 3. GitHub Pages 켜기
저장소 **Settings → Pages → Branch: `main` / `(root)` → Save**를 누릅니다. 1~2분 뒤 위쪽에 사이트 주소가 나옵니다.

### 4. 확인
- `…/teacher.html`에서 비밀번호 `1234`로 로그인합니다. 그다음 구글 시트 **[설정]** 탭에서 `선생님비밀번호`를 바로 바꿉니다.
- 학생 화면에서 `1반 / 테스트 / 1234`로 로그인해 봅니다.

## 사용하기

### 단어 넣기 — 구글 시트 [단어] 탭
`단원 | 단어 | 뜻 | 유의어 | 반의어` 순서로 붙여넣습니다. 받은 엑셀 파일에서 그대로 복사해도 됩니다.
- 유의어·반의어가 여러 개면 쉼표로 구분하고, 없으면 비워 둡니다.
- 단원 순서는 시트에 처음 나오는 순서입니다.
- 예시 단어는 지우고 쓰세요.

### 학생 넣기 — [학생] 탭
`반 | 이름 | 비밀번호`를 입력합니다. 비밀번호는 숫자 4자리 정도를 권장합니다. 학생 비밀번호 변경도 여기서 합니다.

### 설정 — [설정] 탭
통과 기준(%), 한 번에 낼 문항 수(0 = 단원 전체), 단원 잠금(예/아니오), 선생님 비밀번호, 화면 제목을 바꿀 수 있습니다.

### 선생님 화면 (`teacher.html`)
- **학생 현황**: 현재 위치, 완료 단원, 시험 횟수, 정답률, 틀린 단어, 많이 틀린 단어 TOP 15, CSV 내보내기를 봅니다. 학생 이름을 누르면 상세 정보가 나옵니다.
- **시험지 만들기**: 틀린 단어 N개 + 랜덤 단어 M개로 만듭니다.
  - 학생별 시험지 또는 공통 시험지를 고를 수 있습니다.
  - 형식은 객관식 / 뜻 쓰기 / 단어 쓰기 / 혼합 중에서 고르고, 유의어·반의어 문항과 정답지를 넣을 수 있습니다.
  - **미리보기 · 인쇄** 또는 **구글 드라이브에 PDF 저장**을 누릅니다.
- **예약 저장**: 정한 시각(5분 단위로 확인)에 시험지 PDF를 드라이브에 자동 저장합니다. 반복은 한 번 / 매일 / 평일 / 매주 중에서 고릅니다. 저장된 파일은 같은 화면에서 열거나 내려받습니다.
  - Mac에 Google Drive 앱을 설치하면 폴더가 Mac에도 자동으로 동기화됩니다.
- **학생 링크**: 학생에게 줄 링크, QR코드, 안내문이 있습니다.

## 코드를 고친 뒤
- 화면(`*.html`, `*.js`, `*.css`)을 고쳤다면 GitHub에 올리기만 하면 됩니다. 1~2분 뒤 반영됩니다.
- `Code.gs`를 고쳤다면 Apps Script에 다시 붙여넣은 뒤 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포**를 누릅니다. URL은 그대로 유지됩니다.

## 참고
- 학생 비밀번호를 8번 연속 틀리면 그 계정은 10분 동안 로그인할 수 없습니다.
- 통과 여부는 서버(Apps Script)가 채점해서 기록합니다.
- 학생 기록은 이 저장소가 아니라 선생님 구글 시트에만 저장됩니다. 저장소를 공개(public)로 둬도 학생 정보는 노출되지 않습니다.
